# Capturas reales del sistema

Este documento registra las vistas reales del ERP PharmaERP 360 tomadas directamente desde la aplicación ejecutándose en localhost.

## Pantallas documentadas

- Login institucional
- Dashboard principal
- Menú lateral con módulos del sistema
- Vista de módulos de productos y catálogo
- Flujo de facturación demo

## Nota importante

Las capturas que se publican en el repositorio deben corresponder a la interfaz real del sistema para reflejar el estado auténtico del proyecto y evitar imágenes sintéticas o mockups.

## Recomendación

Para una presentación final más profesional, se recomienda:

1. Mantener la aplicación levantada localmente.
2. Tomar capturas de cada pantalla principal.
3. Guardarlas en la carpeta `docs/screenshots/` con formato PNG o JPG.
4. Actualizar el README para enlazar a esas capturas reales.
